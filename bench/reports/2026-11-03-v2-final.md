# OpenPhoneUse benchmark, suite v2: final run

- **Run:** 2026-11-03, GPT-6.1 Terra, fast mode, Android emulator (API 36.1) started with `-gpu host`.
- **Build:** this run predates this release's sign-in changes and has not been repeated since. The fast mode switch was on. The run's logs do not show which sign-in route it used; a discarded run about two hours earlier reached `chatgpt.com`, the old route. Scores and times may differ on the current build.
- **Starting state:** every task loads the same emulator snapshot first, with the clock set to the real time.
- **Grading:** device checks and reply regexes are scored automatically. The remaining items were scored blind from the reply and the screenshots by a judge model (Claude Sonnet, tasks split across three instances). Run labels hid which model ran.
- **Score:** 94.5 / 100 across 31 tasks. Median task time 42 s, whole suite 45 min.
- **A discarded run:** the first final run (with `-gpu swiftshader_indirect -no-window`) captured blank screenshots, so the agent saw only the accessibility tree and the judge had no evidence. It was thrown out. `run.py` now refuses to start when a screen capture comes back blank.
